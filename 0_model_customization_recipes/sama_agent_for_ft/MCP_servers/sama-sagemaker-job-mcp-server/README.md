# SAMA SageMaker Job MCP Server

Launch SFT and GRPO training jobs on SageMaker and monitor their status.

## Tools

| Tool | Description |
|---|---|
| `launch_sft_training_job` | Launch an SFT training job on SageMaker |
| `launch_grpo_training_job` | Launch a GRPO RLVR training job on SageMaker |
| `monitor_training_job` | Check status of a running/completed job |
| `list_recent_training_jobs` | List recent training jobs with optional name filter |

## Installation

```bash
pip install -e .
```
