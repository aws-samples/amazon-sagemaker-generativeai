# SAMA GRPO Recipe Generator MCP Server

Generate YAML recipes for GRPO RLVR training with tool-calling reward functions.

## Tools

| Tool | Description |
|---|---|
| `generate_grpo_recipe` | Generate a GRPO RLVR recipe YAML |
| `list_grpo_recipes` | List existing GRPO recipes |

## Installation

```bash
pip install -e .
```
